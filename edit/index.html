Site editor

This turns on an Edit button on every post and page with words of your own, in this browser only. Tap it, change the words, press Save, and the website updates in about three minutes. Every save is recorded on GitHub, so nothing is ever lost.

1. Make a key on GitHub (once)

  1. Open GitHub's new fine-grained token page (signed in as dcisbusy).
  2. Token name: Site editor. Expiration: a year (GitHub will remind you).
  3. Repository access: Only select repositories → dcisbusy/davidcharlesinfo.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else.
  5. Press Generate token and copy it (it starts github_pat_). GitHub shows it only once.

2. Paste it here (once per phone or computer)


3. Edit

Open any post or page and tap Edit at the bottom right: everything you can change gets a dashed outline. Bold, italic and links are on the toolbar for the main text (short lines such as book and series descriptions are plain text); Undo and Cancel are there if something goes wrong. Titles, dates, photos and counted lines aren't editable here: ask Claude for those.

The key stays in this browser's storage. If your phone is lost, delete the token on GitHub (Settings → Developer settings → Fine-grained tokens) and it stops working at once.
